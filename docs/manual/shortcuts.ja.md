# キーボード ショートカット

[English](shortcuts.md) | [한글](shortcuts.ko.md) | [日本語](shortcuts.ja.md) | [Deutsch](shortcuts.de.md)

> macOS では、`Ctrl` が自動的に `⌘` として表示されます。

## グローバル

| Shortcut | Action | Notes |
|---|---|---|
| `Ctrl+P` | Command Palette | 名前で任意のメニュー コマンドを検索して実行します |
| `Ctrl+F` | 検索を開く | コンテキスト対応：履歴を閲覧しているときはコミット ログ検索、ファイルを表示しているときはファイル内テキスト検索 |
| `Shift+F` | サイドバーの表示/非表示 | サイドバーを折りたたむまたは展開します（タブ ストリップは表示されたままです） |
| `` Ctrl+` `` | ターミナルの表示/非表示 | 下部の組み込みターミナル パネルを開くまたは閉じます |
| `Ctrl+,` | 設定を開く | Settings ビューに切り替えます |

## ブランチ

| Shortcut | Action | Notes |
|---|---|---|
| `Delete` | 選択したブランチを削除 | サイドバーのブランチ行にフォーカスがある場合、またはそのコンテキスト メニューが開いている場合。現在チェック アウトされているブランチは保護されます |

## Diff ビュー（コミットまたはワーキング コピー）

| Shortcut | Action | Notes |
|---|---|---|
| `[` | 前の hunk | 入力/textarea にフォーカスがない場合のみ |
| `]` | 次の hunk | 同じ |

## Merge Editor（競合の解決）

| Shortcut | Action | Notes |
|---|---|---|
| `[` | 前の競合 | 結果パネルをそこまでスクロールします |
| `]` | 次の競合 | 同じ |
| `Esc` | インライン編集をキャンセル | hunk のインライン編集 textarea にフォーカスがある場合 |

## コミット入力

| Shortcut | Action | Notes |
|---|---|---|
| `Ctrl+Enter` | コミット | コミット メッセージ textarea にフォーカスがあり、空でない場合 |

## モーダル / インライン入力

| Shortcut | Action | Notes |
|---|---|---|
| `Esc` | 閉じる / キャンセル | モーダル、コンテキスト メニュー、ツールチップ、ドロップダウンを閉じます |
| `Enter` | フォームを送信 | 例えば Clone または Stash モーダルを単一行入力で送信します |
