# Tastaturkürzel

[English](shortcuts.md) | [한글](shortcuts.ko.md) | [日本語](shortcuts.ja.md) | [Deutsch](shortcuts.de.md)

> Auf macOS wird `Ctrl` automatisch als `⌘` angezeigt.

## Global

| Shortcut | Action | Notes |
|---|---|---|
| `Ctrl+P` | Command Palette | Suchen und führen Sie jeden Menübefehl nach Name aus |
| `Ctrl+F` | Suche öffnen | Kontextabhängig: Commit-Log-Suche beim Durchsuchen des Verlaufs, Textsuche in Dateien beim Anzeigen einer Datei |
| `Shift+F` | Seitenleiste ein-/ausblenden | Klappt die Seitenleiste ein oder aus (Registerleiste bleibt sichtbar) |
| `` Ctrl+` `` | Terminal ein-/ausblenden | Öffnet/schließt das eingebettete Terminal-Fenster unten |
| `Ctrl+,` | Einstellungen öffnen | Wechselt zur Einstellungsansicht |

## Zweige

| Shortcut | Action | Notes |
|---|---|---|
| `Delete` | Ausgewählten Zweig löschen | Wenn eine Zweig-Zeile in der Seitenleiste den Fokus hat oder sein Kontextmenü offen ist. Der derzeit ausgecheckten Zweig ist geschützt |

## Diff-Ansicht (Commit oder Arbeitskopie)

| Shortcut | Action | Notes |
|---|---|---|
| `[` | Vorheriger Hunk | Nur wenn der Fokus nicht in einem Input/Textarea liegt |
| `]` | Nächster Hunk | Dasselbe |

## Merge Editor (Konfliktlösung)

| Shortcut | Action | Notes |
|---|---|---|
| `[` | Vorheriger Konflikt | Scrollt das Ergebnis-Fenster dorthin |
| `]` | Nächster Konflikt | Dasselbe |
| `Esc` | Inline-Bearbeitung abbrechen | Während der Fokus in der Inline-Bearbeitung textarea eines Hunks liegt |

## Commit-Eingabe

| Shortcut | Action | Notes |
|---|---|---|
| `Ctrl+Enter` | Commit | Wenn die Commit-Nachricht textarea den Fokus hat und nicht leer ist |

## Modals / Inline-Eingaben

| Shortcut | Action | Notes |
|---|---|---|
| `Esc` | Schließen / Abbrechen | Schließt Modals, Kontextmenüs, Tooltips und Dropdowns |
| `Enter` | Formular absenden | Z. B. Clone oder Stash Modals mit einer Eingabezeile |
