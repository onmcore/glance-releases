## インストール

[Releases](../../releases/latest) ページから最新のインストーラーをダウンロードして実行してください。その後、Glance は自動的に更新されます — チャンネルを切り替えたい場合（[トラブルシューティング](troubleshooting.ja.md#アップデートチャンネル)を参照）を除き、以降のバージョンを手動でダウンロードする必要はありません。

インストーラーを初めて実行する際に、Windows から **「Windows はこのPC を保護しました」** という SmartScreen の警告が表示される可能性があります。これは何か悪意あるもののせいではありません — Glance はコード署名されていないだけです。署名証明書は継続的なコストがかかるため、無料で個人開発しているプロジェクトはそのための予算がないのです。**詳細情報→ 実行** をクリックして続行してください。

## リポジトリを開く

初回起動時、Glance は **Recent Repositories** リスト（最初は空）とともに、以下のオプションを表示します:

- 既存のローカルリポジトリを **Open**
- URL（HTTPS または SSH）からリポジトリを **Clone**

複数のリポジトリを同時に開いておくことができ、サイドバーのリポジトリスイッチャーで切り替えられます。クローンはバックグラウンドで実行されるため、クローンを開始したままで別のリポジトリで作業を続けることができます。

SSH でクローンする場合にまだキーを設定していなければ、コアワークフローの [SSH 設定](workflows.ja.md#sshリモート)を参照してください。

## インターフェースの見どころ

左側のサイドバーには、上から下へ 5 つのタブがあります:

| タブ | 表示内容 |
|---|---|
| **Branches** | コミット履歴グラフ、refs（ブランチ/リモート/タグ）、stash |
| **Changes** | ワーキングディレクトリのステージング領域（staged / unstaged / conflicts） |
| **File Explorer** | 変更状態に関係なく、リポジトリ全体のファイルツリー |
| **Timeline** | HEAD の移動履歴を時系列で表示する reflog — undo 機能付き |
| **Settings** | Git 設定、エンジン、外観、エディター、アップデート、SSH キー、ライセンス |

コミット、ブランチ、またはファイルを選択すると、その詳細が右側のパネルに開きます — コミットのメタデータと diff、ファイルの内容、または競合解決エディターが、状況に応じて表示されます。
