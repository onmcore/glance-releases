# Glance-Handbuch

[English](README.md) | [한글](README.ko.md) | [日本語](README.ja.md) | [Deutsch](README.de.md)

![Glance-Übersicht: Seitenleiste, Commit-Graph und Detailbereich](assets/screenshots/hero.png)

Ein kurzer, praktischer Leitfaden zur Verwendung von Glance. Wenn Sie bereits ein Git GUI verwendet haben, werden Sie sich in wenigen Minuten zurechtfinden — dieses Handbuch behandelt hauptsächlich, wo sich die Funktionen befinden und was anders ist.

## Inhalt

1. [Erste Schritte](getting-started.de.md) — Installation, Repository öffnen oder klonen, Interface-Überblick
2. [Leistung](performance.de.md) — Warum Glance auf großen Repositories schnell bleibt und Benchmarks
3. [Grundlegende Workflows](workflows.de.md) — Verlauf, Staging, Branching, Remotes, SSH, Diff, Timeline
4. [Tastaturkürzel](shortcuts.de.md)
5. [Fehlerbehebung](troubleshooting.de.md) — Update-Kanäle, integrierte Wiederherstellung, Fehlerberichte

## Die Oberfläche, in einem Absatz

Die linke Seitenleiste hat fünf Reiter: **Branches** (Commit-Verlauf und Graph), **Changes** (Staging-Bereich), **File Explorer** (Dateibaum des Repositories), **Timeline** (reflog-basierter Verlauf und Rückgängigmachen) und **Settings** unten. Wenn Sie einen Commit, Branch oder eine Datei auswählen, werden die Details im rechten Bereich geöffnet.

Weitere Informationen finden Sie in der [README](../../README.de.md) oder [erstellen Sie ein Issue](https://github.com/onmcore/glance-releases/issues/new), falls etwas fehlt oder falsch ist.
