## The interface, in one paragraph

The left sidebar has five tabs: **Branches** (commit history and graph), **Changes** (staging area), **File Explorer** (repo file tree), **Timeline** (reflog-based history and undo), and **Settings** at the bottom. Selecting a commit, branch, or file opens details in the panel on the right.

For anything not covered here, see the main [README](../../README.md), or [open an issue](https://github.com/onmcore/glance-releases/issues/new) if something's missing or wrong.
