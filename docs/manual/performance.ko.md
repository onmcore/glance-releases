# 성능

[English](performance.md) | [한글](performance.ko.md)

Glance는 대형 저장소에서도 반응성을 잃지 않는다는 목표 하나로 만들어졌습니다.

## 체감되는 부분

- 커밋 수십만 개짜리 저장소를 열어도 UI가 멈추지 않습니다 — 커밋 그래프가 가상화되어 있어, 목록이 커져도 스크롤이 끊기지 않습니다.
- 많은 파일을 건드리는 작업(rebase, merge, pull) 이후에도 전체 재스캔이 일어나지 않습니다 — 바뀐 부분만 갱신합니다.
- 알려진 파일 목록만 건드리는 checkout·pull·stash는 나머지 워킹 트리를 전부 훑지 않고 건너뜁니다.
- 디스크의 파일 변경(Git, 다른 툴, OS 무엇이든)이 눈에 띄는 지연 없이 UI에 반영됩니다.

## 왜 이렇게 되는가

- **Electron이 아닌 Tauri v2 + Rust.** 번들된 Chromium 런타임이 없어 설치본이 작고 기본 메모리 사용량도 낮습니다.
- **주 Git 엔진은 gitoxide(`gix`).** 대부분의 작업이 `git.exe`를 매번 실행하는 대신 순수 Rust 구현으로 처리됩니다. gitoxide가 아직 지원하지 않는 작업은 `libgit2` 또는 Git CLI로 자동 전환됩니다.
