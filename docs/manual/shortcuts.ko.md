# 키보드 단축키

[English](shortcuts.md) | [한글](shortcuts.ko.md)

> macOS에서는 `Ctrl`이 자동으로 `⌘`로 표시됩니다.

## 글로벌

| 단축키 | 동작 | 설명 |
|---|---|---|
| `Ctrl+F` | 검색 열기 | 맥락별 분기 — 히스토리 탐색 중이면 커밋 로그 검색, 파일 보기 중이면 파일 내부 텍스트 검색 |
| `Shift+F` | 사이드바 접기/펴기 | 사이드바를 접거나 펼침(탭 스트립은 유지) |
| `` Ctrl+` `` | 터미널 열기/닫기 | 하단의 내장 터미널 패널 토글 |
| `Ctrl+,` | 설정 열기 | Settings 화면으로 전환 |

## 브랜치

| 단축키 | 동작 | 설명 |
|---|---|---|
| `Delete` | 선택 브랜치 삭제 | 사이드바 브랜치 행에 포커스가 있거나 컨텍스트 메뉴가 열려 있을 때. 현재 체크아웃된 브랜치는 보호됨 |

## Diff 뷰 (커밋 또는 워킹 카피)

| 단축키 | 동작 | 설명 |
|---|---|---|
| `[` | 이전 hunk로 이동 | 입력 포커스가 input/textarea가 아닐 때만 |
| `]` | 다음 hunk로 이동 | 동일 |

## Merge Editor (충돌 해결)

| 단축키 | 동작 | 설명 |
|---|---|---|
| `[` | 이전 충돌로 이동 | result 패널을 해당 위치로 스크롤 |
| `]` | 다음 충돌로 이동 | 동일 |
| `Esc` | 인라인 편집 취소 | hunk 인라인 편집 textarea에 포커스가 있을 때 |

## 커밋 입력

| 단축키 | 동작 | 설명 |
|---|---|---|
| `Ctrl+Enter` | 커밋 실행 | 커밋 메시지 textarea에 포커스가 있고 메시지가 비어있지 않을 때 |

## 모달 / 인라인 입력

| 단축키 | 동작 | 설명 |
|---|---|---|
| `Esc` | 닫기/취소 | 모달·컨텍스트 메뉴·툴팁·드롭다운 모두 동일하게 닫힘 |
| `Enter` | 폼 제출 | Clone·Stash 모달 등 한 줄 입력 후 제출 |
